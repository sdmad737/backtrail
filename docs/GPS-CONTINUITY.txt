TRAVIS — GPS-LOSS GUIDANCE CONTINUITY — OCTOBER 24, 2026

PROBLEM AND FIX
Fresh-GPS requirements were applied to both route matching and presentation, and
also disabled the compass sensor lifecycle. This erased useful historical guidance.
GPS outages now retain the last measured route bearing, distance and muted map
position. A reliable live compass keeps rotating the arrow. The UI says LAST KNOWN,
shows age and explicitly holds distance/progress. It never estimates movement from
accelerometer data. If the compass itself is unreliable, the saved bearing remains
available as a labelled fixed north-up reference.

BOUNDARIES
LiveSensors.fix remains the actual observation, including null/weak states. Retained
coordinates never enter RouteFollower, route persistence, arrival, reminders or
confirmation. Approach haptics are disabled for held guidance. Changing journey,
mode, target or cursor clears the old direction. Ambiguous/off-route/gap/near-place
uncertainty still suppresses directional instructions. No prior measured bearing
means none is invented; this does not add GPS-free positioning or inertial navigation.
This display snapshot lasts for the current app session, not across process restarts.
GPS recording, local inference and stored photos/models are unchanged.
Sensors still stop when Map/Camera is hidden or the app backgrounds. No extra sensor,
model inference, network call, 3D engine or continuously running animation was added.
