Honest reading: Gemma’s per-photo generation is only 1.1 to 1.25× faster on the NPU; the wins are load time (4.6× vs GPU, 8.1× vs CPU), memory (3.7× less than CPU) and the embedding path. The NPU uses Google’s Tensor G6 build of each model; GPU and CPU use the generic build.

Pixel 11 Pro, Android 17, airplane mode, LiteRT-LM 0.18.0. Full runs with timestamps: docs/INFERENCE-LOG.md.

Lead with the honest sentence, it buys credibility for everything else: generation is only slightly faster, but load, memory and embeddings are where the NPU changes the product. 1.5 s load means the model can be dropped and reloaded; 851 MB means it coexists with the camera and the map; 13 ms embeddings mean search feels instant.
