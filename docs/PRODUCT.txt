AUTHORITY
The latest user request and TRAVIS-BUILD-BRIEF.txt supersede earlier optional-AR,
visual-only dead-reckoning and GPS-only briefs. Preserve the chosen Android starter.
Previous bootstrap decisions remain under history/ for provenance, not current scope.

PROMISE AND CORE LOOP
Know where you are, record where you have been, remember meaningful places and
help retrace the actual ordered route with no cloud runtime dependency.
Start outing -> record -> save photo + optional note/reminder -> ask/select a
saved memory -> Find in AR -> recognize the original landmark -> resume retrace
or explicitly mark the requested pickup collected -> return to recorded start.

CORE SURFACES
Map: prepared offline surroundings, measured position/uncertainty, segmented
recorded route and photo markers. Missing map coverage leaves the trace visible.
AR: live rear camera and approximate direction along a local look-ahead on the
ordered recorded trail, with approximate remaining route length. Explicit direct
Find uses a straight-line bearing only when GPS can resolve it.
Show the original photo where available. During GPS loss retain the last measured
route pointer and distance as explicitly labelled historical reference; freeze
progress and arrival checks. Keep the live compass independent of GPS quality.
If heading itself is unreliable, show a labelled north-up bearing reference. No photo is silently borrowed from another checkpoint.
Full-screen map/camera, compact guidance and Map/Camera/Travis/Journeys tabs make
the current journey visible. Capture is photo first, then review, optional note
and Save place. Journeys can be renamed. Find
and Retrace are distinct modes sharing one source of truth across Map/AR.
Selecting a memory never advances or replaces the saved retrace cursor.

GEMMA'S ROLE
Ask Travis is an on-device conversation powered by Gemma 4 E2B + LiteRT-LM.
Text or an explicitly recorded voice question can reference recent conversation,
saved photos/notes, measured route order/distances, gaps, next waypoint and goal.
Context is bounded to 12 selected memories and six recent message turns; active
and recently cited places are prioritized. Original photos remain directly inspectable.
Citations are validated against allowed IDs and session/request/revision identity.
Voice records at most 20 seconds in foreground memory, transcribes using Gemma's
local audio encoder, then asks in the same conversation. No cloud speech service.
Read aloud uses an installed offline Android voice; unavailable voices stay visible.
Conversation history is session-only and clears when switching journeys/restarting.
No fabricated coordinates, model-driven progress or automatic recognition claims.
Failures stay explicit and never stop independent GPS recording. G6/NPU is preferred
when its pinned asset is present; generic/GPU remains the explicit compatible option.
Two-photo comparison supports human recognition; it never supplies a position fix.
Trip/photo questions, reminder proposals and editable descriptions remain available.

DETERMINISTIC RESPONSIBILITIES
GPS service, segment boundaries, true bearing geometry, quality gates, ordered
reverse traversal, persistence, reminders and explicit confirmation/undo belong
to ordinary code. Retrace stops at recording gaps; it invents no connecting route.
Arrival in Find does not mark a pickup collected. Collection is a separate action.
Return reminders require opt-in, departure, then repeated good arrival fixes.
A requested time reminder uses an inexact local Android alarm.

PLATFORMS AND DEMO
One native Android app is the technical foundation. Portable Explore is an
interactive browser product showcase for iPhone and Android screen sizes. It has
replay coordinates/heading, NPS photo previews and explicitly sample model answers.
It is isolated from saved live outings. Native iOS remains future work.
The native app also has an opt-in Explore mode. Normal startup is live mode and
never silently substitutes fixtures for missing models or sensors.

SCOPE LIMITS
Approximate camera guidance is core; richer world-tracked AR remains a hardware
exploration gate. No ground-anchored arrows, GPS-free localization, autonomous
route planning, shortcuts, route safety certification, rescue transmission,
cloud fallback, survival chatbot, plant-safety verdicts, continuous pocket camera, telemetry or download-at-use assets in the demo.
A physical Pixel trial is the next gate, not a property proven by compilation.
