save a photo/note -> ask/select a saved memory -> Find in AR -> recognize the
original landmark -> resume the ordered retrace or complete a requested pickup.
AR is core. Keep map and camera dominant, controls readable and the current
Find versus Retrace mode obvious. Selecting a memory preserves retrace progress.

Ready, Recording, Capture, Find and Retracing already exist. Start by walking
that flow in the rendered app and identifying the most consequential usability
issues, then fix a small coherent slice. Prioritize original-photo visibility,
clear approximate direction/straight-line distance, an obvious resume-retrace
control, meaningful confirmation and explicit pickup completion. Use the current
visual direction as a foundation; improve hierarchy, copy, touch targets and
purposeful motion without rebuilding the application or adding a competing stack.
