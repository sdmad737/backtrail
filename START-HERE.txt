WHAT TO DO ON YOUR MAC
1. Download and unzip this folder somewhere local, such as ~/Developer.
2. Use one shared Git repository for the Android app. First get a single
   baseline project to compile and launch on a real device.
3. Copy these instructions into that repository. Preserve/merge any existing
   AGENTS.md rather than overwriting repository instructions blindly.
4. The current product specification is docs/PRODUCT.txt. Older conversation
   material is research history; it is not an additional feature checklist.
5. Use prompts/00-bootstrap.txt for the first local Codex session. Only after
   the baseline/interfaces are committed should the three workstreams start.
6. On three laptops: one clone + feature branch + Codex session per person.
   On one Mac: one separate worktree per concurrently editing session.
7. Use the role prompt matching the workstream. docs/WORKFLOW.txt has commands.

TEAM
You: product and UI / branch codex/ui.
Teammate B: local inference / branch codex/inference.
Teammate C: device/data and integration / branch codex/device.
Choose the teammate most comfortable getting an Android build running as C.
If you prefer another assignment, update ownership once before splitting work.
